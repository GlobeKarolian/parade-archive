# Thanksgiving Parade Archive

A year-by-year list of recordings of New York's Thanksgiving Day Parade: full TV
broadcasts, newsreels, home movies and clips. Served at https://karolian.com/parade/.

- `index.html` is the page. `data.json` is the list, one recording per line.
- `hero.jpg` is cropped from a 1979 photo by Jon Harder (Wikimedia Commons, CC BY 2.5).
- `cloudflare/worker.js` is the small Cloudflare Worker that serves these files at
  karolian.com/parade/. Changes pushed to `main` show up within about five minutes.

Fan-kept. Not affiliated with Macy's or NBC.
